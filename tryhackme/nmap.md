# Room: Nmap

## Objective:
Learn how to scan a target to find open ports and services.

## What I learned:
- Nmap is used for network scanning
- It helps find open ports on a system
- It can detect services running on those ports

## Commands Used:
- nmap <target>
- nmap -sV <target>

## Steps I followed:
1. Ran a basic scan on the target
2. Observed open ports
3. Used -sV to identify services

## Example Output (short):
Port 22 - SSH  
Port 80 - HTTP  

## Key Takeaway:
Nmap helps identify open ports and services, which is the first step in security testing.
